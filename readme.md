# Grocery Backend
This is a fully backend application. A Grocery app that manages users, catalog, products, and orders. For the learning purpose I made this app.


## Tools
- Made with Python
- Django RestFramework


## Getting Started
1. Clone this repo

    `git clone https://github.com/PremDanej/blog-backend.git`

2. Go to folder

    `cd grocery_backend`

3. Install all dependencies

    `pip install -r requiremenets.txt`

4. Run the project

    `python manage.py runserver`
